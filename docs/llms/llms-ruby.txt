# modern_colorthief — RUBY Binding API

Package: `modern_colorthief`
Module: `Colorthief`
Install: `gem install modern_colorthief`
Version: 0.3.0

## Functions

### `make_runtime_err(msg: String)` → `error`

  Build a magnus runtime error. Returns a placeholder if the Ruby runtime
  is unavailable (only possible during interpreter shutdown).

  Parameters:
  - `msg` (String)

### `compute_callback(data: *mut std::ffi::c_void)` → `void`

  C ABI function pointer — runs with the GVL released.

  Parameters:
  - `data` (*mut std::ffi::c_void)

### `release_gvl_and_compute(pixel_data: Array<Integer>, width: Integer, height: Integer, color_count: Integer, quality: Integer)` → `Array<Integer>`

  Parameters:
  - `pixel_data` (Array<Integer>)
  - `width` (Integer)
  - `height` (Integer)
  - `color_count` (Integer)
  - `quality` (Integer)

### `get_palette(pixels: String, width: Integer, height: Integer, color_count: Integer, quality: Integer)` → `Array<Integer>`

  Parameters:
  - `pixels` (String)
  - `width` (Integer)
  - `height` (Integer)
  - `color_count` (Integer)
  - `quality` (Integer)

### `get_color(pixels: String, width: Integer, height: Integer, quality: Integer)` → `Array<Integer>`

  Parameters:
  - `pixels` (String)
  - `width` (Integer)
  - `height` (Integer)
  - `quality` (Integer)

## Usage Example

```ruby
require "Colorthief"

palette = Colorthief.get_palette(pixels, width, height, 5, 1)
color   = Colorthief.get_color(pixels, width, height, 1)
```
