description: 'Use Modern Colorthief from Java or Kotlin via JNI bindings.'

:::info
Artifact: `modern-colorthief` JAR · Download from [GitHub Releases](https://github.com/baseplate-admin/modern_colorthief/releases)
:::

JVM bindings use JNI. Targets Java 26 and is Android-compatible. Java AWT handles image decoding if you want file-path convenience; otherwise pass a raw RGBA `byte[]`.

## Functions

- **`Colorthief.getColor(pixels, width, height, quality)`** → `byte[]` of 3 (R, G, B)
- **`Colorthief.getPalette(pixels, width, height, colorCount, quality)`** → `byte[][]` of [R, G, B] rows

`pixels` is a `byte[]` of raw RGBA bytes (4 bytes per pixel, row-major). Java bytes are signed, so values above 127 appear as negatives — mask with `& 0xFF` when reading.

## Raw RGBA pixels — Java

```java
import io.baseplate_admin.modern_colorthief.Colorthief;

// 10×10 solid red: 100 pixels × 4 bytes
byte[] pixels = new byte[400];
for (int i = 0; i < 100; i++) {
    pixels[i * 4]     = (byte) 255; // R
    pixels[i * 4 + 1] = 0;          // G
    pixels[i * 4 + 2] = 0;          // B
    pixels[i * 4 + 3] = (byte) 255; // A
}
byte[] color   = Colorthief.getColor(pixels, 10, 10, 1);
byte[][] palette = Colorthief.getPalette(pixels, 10, 10, 5, 1);

System.out.printf("%d, %d, %d%n", color[0] & 0xFF, color[1] & 0xFF, color[2] & 0xFF);
```

## Raw RGBA pixels — Kotlin

```kotlin
import io.baseplate_admin.modern_colorthief.Colorthief

// 10×10 solid red
val pixels = ByteArray(400)
for (i in 0 until 100) {
    pixels[i * 4]     = 255.toByte()
    pixels[i * 4 + 1] = 0
    pixels[i * 4 + 2] = 0
    pixels[i * 4 + 3] = 255.toByte()
}
val color   = Colorthief.getColor(pixels, 10, 10, 1)
val palette = Colorthief.getPalette(pixels, 10, 10, 5, 1)

println("${color[0].toInt() and 0xFF}, ${color[1].toInt() and 0xFF}, ${color[2].toInt() and 0xFF}")
```

## With AWT

```java
import java.awt.image.BufferedImage;
import java.io.File;
import javax.imageio.ImageIO;

BufferedImage img = ImageIO.read(new File("photo.jpg"));
int w = img.getWidth(), h = img.getHeight();
byte[] pixels = new byte[w * h * 4];
for (int y = 0; y < h; y++) {
    for (int x = 0; x < w; x++) {
        int rgb = img.getRGB(x, y);
        int i = (y * w + x) * 4;
        pixels[i]     = (byte) ((rgb >> 16) & 0xFF);
        pixels[i + 1] = (byte) ((rgb >> 8)  & 0xFF);
        pixels[i + 2] = (byte) ( rgb        & 0xFF);
        pixels[i + 3] = (byte) ((rgb >> 24) & 0xFF);
    }
}
byte[] color   = Colorthief.getColor(pixels, w, h, 10);
byte[][] palette = Colorthief.getPalette(pixels, w, h, 10, 10);
```
