---
title: 'PHP'
description: 'Use Modern Colorthief from PHP via the modern_colorthief extension.'
---

:::info
Extension: `modern_colorthief` · Build from source and enable in `php.ini`
:::

PHP bindings use the `ext-php-rs` crate. GD (or Imagick) handles image decoding if you want file-path convenience; otherwise pass a raw RGBA `array` or `string` of bytes.

## Enabling the extension

After building, add to `php.ini`:

```ini
extension=modern_colorthief.so
```

## Functions

- **`get_color($pixels, $width, $height, $quality=10)`** → `[r, g, b]`
- **`get_palette($pixels, $width, $height, $color_count=10, $quality=10)`** → `[[r, g, b], ...]`

`$pixels` is a raw RGBA byte string (4 bytes per pixel, row-major), or a flat array of byte values.

## Raw RGBA pixels

```php
<?php
// 10×10 solid red: 100 pixels × 4 bytes
$pixels = [];
for ($i = 0; $i < 100; $i++) {
    $pixels[] = 255; // R
    $pixels[] = 0;   // G
    $pixels[] = 0;   // B
    $pixels[] = 255; // A
}
$color   = get_color($pixels, 10, 10, 1);
$palette = get_palette($pixels, 10, 10, 5, 1);

print_r($color);
```

## With GD

```php
<?php
$img   = imagecreatefromjpeg("photo.jpg");
$width = imagesx($img);
$height = imagesy($img);

$pixels = str_repeat("\0", $width * $height * 4);
for ($y = 0; $y < $height; $y++) {
    for ($x = 0; $x < $width; $x++) {
        $rgb  = imagecolorat($img, $x, $y);
        $i    = ($y * $width + $x) * 4;
        $pixels[$i]     = chr(($rgb >> 16) & 0xFF);
        $pixels[$i + 1] = chr(($rgb >> 8)  & 0xFF);
        $pixels[$i + 2] = chr($rgb & 0xFF);
        $pixels[$i + 3] = chr(0xFF);
    }
}
$color   = get_color($pixels, $width, $height, 10);
$palette = get_palette($pixels, $width, $height, 10, 10);
```
