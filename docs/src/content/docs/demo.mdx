Drop an image below, or paste an image URL. The demo runs the Rust core
entirely in your browser, with nothing uploaded anywhere:

- **Auto** (default): uses the **WebGPU** compute binding when your browser
  supports it, and falls back to the **WASM** CPU binding otherwise.
- **WebGPU** / **WASM**: force a specific engine from the selector below the
  drop zone.

Both engines decode the image in your browser and run the same core algorithm.
