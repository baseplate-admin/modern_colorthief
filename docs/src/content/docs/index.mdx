**Modern Colorthief** extracts dominant color palettes from images at high speed. The core is a hand-rolled median-cut algorithm in Rust with rayon parallelism, and the same API is exposed across six language bindings.

## Two functions, everywhere

Every binding exposes the same two functions with the same parameter names and the same return shape:

- **`getPalette(image, colorCount?, quality?)`** → an array of `[R, G, B]` colors
- **`getColor(image, quality?)`** → the single dominant `[R, G, B]` color

Image decoding is handled by the host language (Pillow, Sharp, Canvas, AWT, `image_processing`, GD). The Rust core always receives raw RGBA bytes, so the algorithm - and its results - are identical no matter which language you call from.

## Why Rust

A median-cut quantizer sounds simple, but the hot loop is pure arithmetic over every pixel. In Rust, with rayon splitting the work across cores and release LTO inlining the inner loop, `modern_colorthief` is roughly **100× faster** than the original pure-Python `colorthief` and on par with or faster than the C++ `fast_colorthief` - see the [benchmarks](benchmarks/) for reproducible numbers.
