Modern Colorthief publishes [`llms.txt`](https://llmstxt.org/) files so that LLMs and AI coding assistants can get accurate, up-to-date API reference without scraping the full docs site.

## What is llms.txt?

`llms.txt` is a plain-text file that summarizes a project's API for machine consumption. Each binding has its own file with the exact function signatures, parameter names, return types, and install commands.

## Files

| File | Contents |
| ---- | -------- |
| [`llms.txt`](../llms.txt) | Index and common API across all bindings |
| [`llms-full.txt`](../llms-full.txt) | Full API reference for every binding |
| [`llms-python.txt`](../llms-python.txt) | Python API |
| [`llms-nodejs.txt`](../llms-nodejs.txt) | Node.js API |
| [`llms-wasm.txt`](../llms-wasm.txt) | WebAssembly API |
| [`llms-java.txt`](../llms-java.txt) | JVM (Java/Kotlin) API |
| [`llms-ruby.txt`](../llms-ruby.txt) | Ruby API |
| [`llms-php.txt`](../llms-php.txt) | PHP API |

## How to use

### In a system prompt

```text
You are helping a developer use the modern_colorthief library.
Read the API reference here before answering:
https://modern-colorthief.readthedocs.io/en/latest/llms.txt
```

### In Cursor / Windsurf rules

Add to `.cursorrules` or `.windsurfrules`:

```text
For modern_colorthief API details, fetch:
https://modern-colorthief.readthedocs.io/en/latest/llms-python.txt
```

### In a RAG pipeline

```python
import requests
resp = requests.get("https://modern-colorthief.readthedocs.io/en/latest/llms-full.txt")
docs_text = resp.text  # use as context
```

## Regeneration

Read the Docs regenerates these files from the checked-out binding source and manifests during each build. The links above serve the API reference for this docs version.
