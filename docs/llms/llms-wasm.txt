# modern_colorthief — WASM Binding API

Package: `@modern_colorthief/wasm`
Module: `@modern_colorthief/wasm`
Install: `npm install @modern_colorthief/wasm`
Version: 0.3.0

## Functions

### `rejectStr(p: js_sys::Function, msg: str)` → `void`

  Parameters:
  - `p` (js_sys::Function)
  - `msg` (str)

### `paletteToJsArray(palette: [(u8, u8, u8)])` → `Promise`

  Build a JS array of `number[][]` from an `Rgb` palette.

  Parameters:
  - `palette` ([(u8, u8, u8)])

### `colorToJsArray(r: number, g: number, b: number)` → `Promise`

  Build a JS array of `number[]` — `[R, G, B]` — from a single color.

  Parameters:
  - `r` (number)
  - `g` (number)
  - `b` (number)

### `getPalettePromise(image: any, color_count: number, quality: number)` → `Promise`

  Extract a palette of dominant colors from an image.
  
  Accepts a string URL, `Uint8Array`, or `ArrayBuffer` of raw image bytes.
  Uses the browser's Canvas API to decode, then runs Median Cut in Rust.
  

  Parameters:
  - `image` (any)
  - `color_count` (number)
  - `quality` (number)

### `getColorPromise(image: any, quality: number)` → `Promise`

  Extract the dominant color from an image.
  
  The dominant color is the **first** entry of a 5-color palette.
  
  # Returns

  Parameters:
  - `image` (any)
  - `quality` (number)

### `decodeImagePromise(image: any)` → `Promise`

  Decode an image via the browser Canvas API.
  
  # Returns
  Promise resolving to `{ pixels: Uint8Array, width: number, height: number }`.

  Parameters:
  - `image` (any)

### `getPaletteFromPixels(pixels: Uint8Array, width: number, height: number, color_count: number, quality: number)` → `Promise`

  Extract a palette from raw RGBA pixel data (no image decoding).

  Parameters:
  - `pixels` (Uint8Array)
  - `width` (number)
  - `height` (number)
  - `color_count` (number)
  - `quality` (number)

### `getColorFromPixels(pixels: Uint8Array, width: number, height: number, quality: number)` → `Promise`

  Extract the dominant color from raw RGBA pixel data (no image decoding).

  Parameters:
  - `pixels` (Uint8Array)
  - `width` (number)
  - `height` (number)
  - `quality` (number)

### `decodeImageAsync(image: any)` → `Result`

  Decode an image via the browser Canvas API (async).
  
  Returns a future resolving to `(Uint8Array, width, height)`.

  Parameters:
  - `image` (any)

## Usage Example

```javascript
import { getPalette, getColor } from '@modern_colorthief/wasm';

const palette = await getPalette(pixels, width, height, 5, 1);
const color   = await getColor(pixels, width, height, 1);
```
