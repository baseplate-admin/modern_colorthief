description: 'Planned features and future work for Modern Colorthief.'
---

## Now (0.3.x)

- ✅ Python, Ruby, Node.js, JVM, PHP, WASM bindings
- ✅ Raw RGBA pixel API across all bindings
- ✅ Median-cut algorithm with rayon parallelism
- ✅ Python CLI

## Near-term

- **GPU acceleration** — Vulkan Compute for native bindings (cross-vendor: Intel, AMD, NVIDIA) and WebGPU for WASM to offload the median-cut split to the GPU.
- **Package publishing** — Publish all six bindings to their respective registries (PyPI, RubyGems, npm, Maven Central, PECL, npm WASM).
- **ReadTheDocs** — Migrate docs from Sphinx to Astro/Starlight (in progress).

## Longer-term

- **WebGPU for WASM** — Full GPU path in the browser.
- **More image formats** — Wider decode support in the Node.js and PHP bindings.
- **Performance profiling** — Continuous benchmarking across platforms in CI.
